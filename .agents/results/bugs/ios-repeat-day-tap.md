# 빌드 70 반복 요일 탭 지연

- 실기기 영상 약 4–11초에 내수동교회 상세 화면에서 토·금요일 선택과 해제가 보임. 영상에는 손가락 접촉 시점이 표시되지 않아 입력부터 표시까지 걸린 시간은 산출할 수 없음.
- 요일 버튼은 한 번의 유효한 탭으로 동작함. 기존에는 공통 상태를 다시 계산해야 선택 테두리와 요약이 바뀌었고, 눌림 효과가 테두리와 글자까지 함께 흐리게 했음. 목적지 알림만 평가할 때도 목적지마다 폭염·호우를 계산했고, 시간대별 예보를 순회할 때 같은 지역의 날짜 포매터를 반복 생성했음.
- 수정 후 버튼은 유효한 탭이 끝나는 시점에 상태 소유자가 반환한 다음 일정으로 요약·선택 테두리·접근성 상태를 먼저 갱신함. 눌림 효과는 배경에만 적용함. 날씨 알림은 요청한 유형만 계산하고 날짜 포매터는 시간대별로 재사용함.
- Node에서 실제 iOS 상태 생성 함수에 저장 목적지 2곳·48시간 예보를 넣어 21회 요일을 교대로 변경함. 동기 구간 중앙값 5.48ms → 0.61ms, 워밍업 후 포매터 생성 164회 → 1회. 실기기 화면 지연 측정값과 구분함.
- 실제 요일 패널과 토글을 사용한 브라우저 검증에서 상위 일정 갱신을 보류해도 토요일 한 번 클릭으로 ‘토 · 일’이 먼저 표시됨. 금요일 선택과 토요일 해제 후 갱신을 재개하자 표시와 최종 상태가 ‘금 · 일’로 일치함. 빠른 7회 입력, 마지막 요일 해제, 저장·미저장 목적지, 날짜·알림·경로 회귀 및 모바일 타입 검사 통과함.
- 수정본의 TestFlight 배포 및 실제 iPhone 재검증은 미실시.
