## 탭 선택 규칙
홈=집 / 코디=셔츠 / 출발=종이비행기 / MY=사람을 그대로 유지합니다.
- 비선택: 1.75 선 + 중성색 + 보통 라벨
- 선택: 같은 원형의 2.0 선 + 선명한 포인트색 + 은은한 배경 + 굵은 라벨
- 선택된 탭도 내부를 채우지 않습니다. 배경은 심벌 내부가 아닌 별도 컨테이너입니다.
- 색 외에 선 굵기·배경·라벨과 접근성 selected 상태를 함께 사용합니다.

라이트 아이콘 #E53C24 / 라이트 선택 배경 #FFE5DE / 라이트 선택 라벨 #B63121.
다크 아이콘·라벨 #FFB52E / 다크 선택 배경 #433A27.
라이트 라벨은 작은 글자 대비를 위해 같은 계열의 더 진한 색을 사용합니다. 홈 워드마크 ON에 적용한 옅은 색 예외를 일반 컨트롤에 확대하지 않았습니다. 정확한 앱 배경에서 다시 검증해야 합니다.

## 날씨와 조작의 역할
날씨 8종은 맑음/흐림/구름 조금/비/강한 비/눈/천둥번개/안개입니다. 큰 날씨는 얕은 면과 공통 광원, 작은 예보는 단순 색면, 조작은 선형을 사용합니다. 모양을 화면마다 다시 생성하지 않습니다.

작은 날씨는 라벨과 함께 사용하세요. 강수확률을 비의 강도로 해석하지 않습니다. 특히 24px의 비/강한 비는 심벌만으로 의미를 전달하지 않습니다. 단색 번개는 구름과 분리해 24px 가독성을 보강했습니다.

야간 맑음·야간 구름·진눈깨비·혼합강수·미확인 등의 추가 상태는 이번8종 범위 밖입니다. 실제 데이터 공급자 코드와 매핑할 때 필요한 자산을 추가하고, 없는 상태를 임의로 맑음 등으로 대체하지 마세요.

## 플랫폼 적용 계획과 한계
공통 SVG는 iOS와 Android에서 공유합니다. iOS Liquid Glass는 주변 컨테이너, Android Material 특성은 톤·상태·피드백에 반영할 계획입니다. 이번 비교판의 탭 배경은 사용 예이며 네이티브 컨테이너 최종 구현이 아닙니다.

보이는 아이콘과 터치 영역은 구분하며 iOS44pt / Android48dp 이상을 목표로 검증하세요. 실제 접근성·스크린리더·기기·모션 검증은 미실시입니다. Final v1은 이번 승인 범위의 자산 마무리를 뜻하며 앱 구현이나 전체 날씨 상태 지원 완료를 뜻하지 않습니다.

이것은 정적 자산입니다. 날씨나 터치에 반응하는 Ambient Surface 동작은 구현하지 않았습니다. 큰 날씨에 사용한 SVG blur/filter의 런타임 지원을 확인해야 합니다. 작은 예보에는 접촉음영 filter가 없습니다.

## SVG 사용
UI는 currentColor 기반입니다. 플랫폼 템플릿이나 인라인 SVG로 적용하세요. 외부 SVG를 HTML img로 쓰면 부모 글자색이 자동 상속되지 않을 수 있습니다. 선택 탭4종에 별도 cutout 색 설정은 필요 없습니다.

날씨 SVG를 같은 DOM에 여러 번 인라인할 때 gradient/clip/filter ID에 인스턴스별 prefix를 붙입니다. 독립 SVG 이미지로 사용하면 문서별 ID가 분리됩니다. 모든 원본은 투명 배경이며 모드별 파일을 명시적으로 선택하세요.
