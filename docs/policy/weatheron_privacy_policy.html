2. 개인정보 이용 목적

  • 회원 식별, 로그인, 계정 관리, 데이터 동기화
  • 현재 위치 기반 날씨, 목적지 비교, 출발 준비 정보 제공
  • 날씨 기반 코디, 우산, 신발, 알림 추천 제공
  • 옷장 사진의 등록 적합성 확인과 카테고리·날씨 태그 제안
  • 서비스 안정성 개선, 오류 분석, 품질 관리

현재 위치 좌표는 이용자가 요청한 날씨·장소·경로 조회 시 WeatherON의 Cloudflare Worker를 거쳐 기상청, Apple WeatherKit, Open-Meteo, Kakao 또는 Google 등 해당 기능 제공자에 전달됩니다. WeatherON 애플리케이션은 실시간 위치 좌표를 D1·R2에 저장하지 않습니다. Worker의 날씨·장소·경로 응답 메모리 캐시 키에는 좌표가 설정된 TTL 동안 일시적으로 포함될 수 있습니다. 제공자 측 로그와 백업은 WeatherON 애플리케이션 저장소와 구분됩니다.

3. 보유 및 이용 기간

  • 회원 정보와 저장 데이터는 회원 탈퇴 또는 삭제 요청 시 지체 없이 파기합니다.
  • 법령상 보관 의무가 있는 정보는 해당 법령에서 정한 기간 동안 보관합니다.
  • 계정 정보와 계정에 연결된 동의 기록은 계정 삭제 시까지 보관합니다. 삭제는 운영 데이터베이스에 적용되며, D1의 시점 복구 이력에는 삭제 전 데이터가 최대 7일간 남을 수 있습니다.
  • 기기 저장 데이터는 앱에서 삭제하거나 앱을 제거할 때까지 보관합니다.
  • 실시간 위치정보는 요청한 날씨·장소·경로 조회에 사용하며 WeatherON 서버 저장소에 별도 보관하지 않습니다.
  • 옷장 사진 원본은 WeatherON 서버 저장소에 보관하지 않습니다. 분석용 축소 JPEG는 등록 적합성 확인 후 요청 처리 범위에서만 사용하며, 승인된 사진 파일은 이용자 기기에 저장됩니다. iOS에서는 iCloud 백업 제외와 기기 잠금 시 파일 보호를 적용합니다.

4. 제3자 제공 및 처리위탁

Cloudflare D1 계정 데이터베이스는 아시아·태평양(APAC) 지역에서 실행되며 읽기 복제는 사용하지 않습니다. APAC은 개별 국가명이 아니며 특정 국가 내 저장을 보장하는 설정이 아닙니다. 이 설정은 Workers·Workers AI의 처리 위치까지 제한하지 않습니다. 현재 운영 Worker의 Workers Logs·Workers Traces와 Logpush는 비활성화되어 있습니다. 이는 Cloudflare의 모든 서비스 운영·보안 기록이 존재하지 않는다는 의미는 아닙니다.

5. 광고 및 마케팅

광고 식별자 기반 광고와 마케팅 메시지 발송 기능은 현재 앱에 적용하지 않습니다. 도입 전 처리 항목·목적·보유기간을 별도 고지하고 필요한 동의를 받습니다.

6. 이용자의 권리와 행사 방법

이용자는 앱의 계정 관리 또는 support@weatheron.app을 통해 개인정보 열람, 정정, 삭제, 처리정지와 동의 철회를 요청할 수 있습니다. 본인 확인 후 지체 없이 처리 결과를 안내합니다. 앱의 계정 삭제 기능은 서버 계정 데이터와 연결된 기기 데이터를 삭제합니다.

7. 위치정보 처리

WeatherON은 현재 위치 날씨, 목적지 케어, 출발 준비 추천을 위해 위치정보를 사용할 수 있습니다. 현재 위치 좌표는 WeatherON의 Cloudflare Worker를 거쳐 해당 날씨·장소·경로 제공자에 전달되며 D1·R2에는 저장하지 않습니다. 위치 권한을 거부해도 수동 위치와 목적지 검색 등 기본 기능은 사용할 수 있습니다. 위치정보의 세부 이용 조건은 위치기반서비스 이용약관을 따릅니다.

9. 개인정보 파기 절차와 방법

계정 삭제 요청이 완료되면 운영 데이터베이스의 계정 행과 연결 데이터를 삭제하고, 기기 데이터베이스 기록과 옷장 사진 파일을 삭제합니다.

10. 안전성 확보조치

전송 구간 암호화, 세션 토큰 해시 저장, 로그인 제공자 토큰 암호화, 앱 무결성 확인, 요청 크기·횟수 제한과 접근 범위 제한을 적용합니다.
