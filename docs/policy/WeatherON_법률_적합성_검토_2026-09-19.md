# WeatherON 법률 적합성 검토

> 후속 확인: [2026-09-20 운영설정 재검토](WeatherON_정책_운영설정_재검토_2026-09-20.md) 참고. Cloudflare 플랜·D1 지역·로그 상태는 실제 확인됐으며, 아래 ‘필수 동의 해소’와 사업자·대표자·국외이전 관련 판단은 후속 문서의 정정·한계를 우선 적용함.

- 기준일: 2026-09-19
- 범위: 한국 개인정보 보호법·위치정보법, 일본 개인정보보호법(APPI), Cloudflare 공식 처리조건
- 결론: 현재 확인된 문서와 구현만으로 외부 공개·동의 수취를 적법하다고 판단할 수 없음. 아래 P0 항목 확인·수정 전 출시 차단 필요함.
- 한계: 법률자문 의견서가 아님. 저장소와 공식 1차 출처로 확인 가능한 사실만 정리했으며, 미확인 사업자·계약·운영 사실을 추정해 채우지 않았음.

## 2. 한국 개인정보 보호법 검토

### 수집·이용 동의

동의에 근거해 개인정보를 수집·이용할 때는 목적, 수집 항목, 보유·이용기간, 동의 거부권과 거부 시 불이익을 알려야 함([개인정보 보호법 제15조 제2항](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398563)). 여러 동의 사항은 구분해 각각 동의를 받아야 하고, 정보주체가 명확히 인지하도록 표시해야 함([제22조 제1항부터 제3항](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1006185927)). 선택 동의를 거부했다는 이유로 서비스 제공을 거부할 수 없음([제22조 제5항](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335467)). 만 14세 미만 아동은 법정대리인 동의 절차가 별도로 필요함([제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523)).

현재 동의 화면에는 제15조 고지 항목이 직접 표시되고 필수 동의 판정 오류도 수정됐음. 다만 실제 보유기간 확인과 운영 D1의 문서별 증적 마이그레이션 적용이 남아 있음.

### 개인정보처리방침

개인정보처리방침에는 처리 목적, 처리·보유기간, 해당 시 제3자 제공, 파기 절차·방법과 법정 보존 정보, 처리위탁, 정보주체와 법정대리인의 권리·행사방법, 개인정보 보호책임자 또는 담당부서 연락처, 자동수집 장치 관련 사항 등 법정 항목을 포함해야 함([개인정보 보호법 제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033215151)). 개인정보가 불필요하게 되면 원칙적으로 지체 없이 파기해야 하고, 법령상 보존 시 다른 개인정보와 분리해야 하며, 복구·재생되지 않는 방법을 사용해야 함([개인정보 보호법 제21조가 포함된 공식 법령집](https://www.law.go.kr/LSW/lbook/lbFileDownload.do?flExt=pdf&lbookConflSeq=54161&lbookSeq=60046)). 개인정보처리자는 분실·도난·유출·위조·변조·훼손 방지를 위한 기술적·관리적·물리적 조치를 해야 함([제29조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079357)).

현재 앱 내 방침은 누락 사실 자체를 본문에 적고 있음. 이는 외부 공개 전 내부 초안임을 드러낼 뿐 제30조상 필수 정보를 충족하지 못함. 특히 데이터 항목별 보유기간, 법적 보존 근거, 백업·로그 파기, 확정된 위탁·제3자 제공·국외이전 구분, 법적 사업자와 권리행사 담당부서가 필요함.

### 국외 이전

Cloudflare 등 국외 사업자가 개인정보를 처리한다면 국외 이전의 법적 근거를 먼저 확정해야 함([개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331899)). 고지 또는 동의에는 이전 개인정보, 국가·시기·방법, 이전받는 자의 명칭과 연락처, 이용 목적·보유기간, 거부 방법과 효과가 포함돼야 함([제28조의8 관련 고지사항](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033215841)). 국외 수탁자 보호조치와 계약상 의무도 확인해야 함([개인정보 보호법 시행령 관련 규정](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=182203)). 실제 처리 국가와 계약이 확인되지 않은 상태에서 국가·기간·수탁관계를 임의로 기재하면 안 됨.

## 3. 위치정보법 검토

개인위치정보 수집사업자와 위치기반서비스사업자의 지위는 실제 데이터 흐름과 사업 형태에 따라 달라지므로 먼저 법적 분류가 필요함. 위치정보사업자가 개인위치정보를 수집하는 경우 약관에 상호·주소·전화번호 등, 이용자 권리와 행사방법, 위치기반서비스사업자에게 제공하는 서비스 내용, 수집사실 확인자료의 보관 근거·기간, 수집 목적과 보유기간을 명시해 동의를 받아야 함([위치정보법 제18조](https://elaw.klri.re.kr/eng_mobile/viewer.do?hseq=61450&key=ACT+ON+THE+PROTECTION+AND+USE+OF+LOCATION+INFORMATION&type=lawname)). 위치기반서비스사업자가 개인위치정보를 이용하거나 제3자에게 제공하는 경우에도 사업자 정보, 권리행사, 서비스 내용, 이용·제공사실 확인자료의 보관 근거·기간, 이용 목적과 보유기간을 약관에 명시해야 하며 제3자 제공 동의와 통지 규칙을 따라야 함(같은 공식 법령의 제19조).

개인위치정보의 수집·이용·제공 사실 확인자료는 자동으로 기록·보존해야 함([같은 공식 법령 제16조 제2항](https://elaw.klri.re.kr/eng_mobile/viewer.do?hseq=61450&key=ACT+ON+THE+PROTECTION+AND+USE+OF+LOCATION+INFORMATION&type=lawname)). 위치정보 보호정책에는 개인위치정보의 이용목적·보유기간, 확인자료 보관 근거·기간, 파기, 제3자 제공 등이 포함돼야 함(같은 법 제21조의2). 목적 달성 시 확인자료와 법령상 보존정보를 제외하고 지체 없이 파기해야 하며(제23조), 이용자는 동의 철회·일시중지와 기록 열람·고지·정정 등을 요구할 수 있음(제24조).

현재 코드에는 확인자료 자동 기록·보존이 확인되지 않고, 사업자 정보와 보관기간도 미확정임. 따라서 현재 위치기반서비스 약관은 출시용으로 확정할 수 없음. 법 조문 자체가 모든 사업자에게 단일 고정 기간을 정한 것으로 보이지 않으므로 `6개월` 같은 기간을 근거 없이 복사하지 말고, 적용되는 시행령·고시·사업 지위와 실제 운영정책을 법률 검토해 확정해야 함.

## 4. 일본 APPI 검토

일본 내 이용자에게 상품·서비스를 제공하면서 그 이용자의 개인정보를 취급하는 외국 사업자에는 일본 개인정보보호법의 역외적용이 문제될 수 있음([일본 개인정보보호위원회 통칙 가이드라인 8절](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)). 일본어 지원만으로 적용 여부를 단정할 수 없고, 실제 일본 대상 제공과 개인정보 처리 사실을 확인해야 함.

적용되는 경우 이용목적을 사전에 공표하거나 취득 후 신속히 통지·공표해야 함([개인정보보호위원회 통칙 가이드라인 3-3-3](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)). 본인에게 알 수 있는 상태로 둘 사항에는 사업자 명칭, 주소와 법인 대표자, 모든 보유개인정보의 이용목적, 이용목적 통지·공개·정정·추가·삭제·이용정지·소거·제3자 제공정지 및 제3자 제공기록 공개의 청구 절차와 수수료, 안전관리조치, 불만 접수처 등이 포함됨(같은 가이드라인 3-8-1). 공개 청구, 정정·추가·삭제, 이용정지·소거·제3자 제공정지와 청구 접수 절차도 마련해야 함(같은 가이드라인 3-8-2부터 3-8-5).

APPI가 반드시 별도 제목의 일본 전용 문서 하나를 요구한다고 단정할 수는 없음. 다만 현재 일본어 번역본은 원문에서 누락된 사업자 주소·대표자, 실제 이용목적·보유정책, 권리행사와 불만처리 절차, 안전관리조치를 보완하지 못하므로 일본 대상 제공 시 충분하지 않음. 한국 원문의 의미와 버전을 유지하되 APPI 적용사항을 사실에 맞게 추가하고 일본 법률 검수를 받아야 함.

## 5. Cloudflare 검토

Cloudflare의 현행 고객 DPA는 적용되는 처리에서 고객과 Cloudflare의 컨트롤러·프로세서 관계를 정하고, Cloudflare가 보호의무를 둔 하위처리자를 일반 승인 방식으로 사용할 수 있다고 규정함([Cloudflare Customer DPA v6.4, 2026-04-03 시행](https://www.cloudflare.com/cloudflare-customer-dpa/)). 실제 하위처리자는 Cloudflare의 동적 목록에서 서비스별로 확인해야 함([Cloudflare Subprocessors](https://www.cloudflare.com/gdpr/subprocessors/)). 공개 DPA와 목록만으로 WeatherON 계정에 실제 적용된 계약, 활성 서비스, 처리 국가와 보유기간은 확정되지 않음.

D1은 생성 요청 위치에 가까운 곳에 기본 배치되며, jurisdiction 지정은 데이터베이스 생성 시에만 가능하고 이후 변경할 수 없음. 문서상 `eu`, `fedramp` 옵션이 있으며, jurisdiction은 D1의 실행·영속 위치를 다루지만 Workers 요청 처리 위치까지 제한하지 않음([Cloudflare D1 data location](https://developers.cloudflare.com/d1/configuration/data-location/)). Workers Regional Services를 사용해도 코드와 시크릿은 전 세계 배포될 수 있고 외부 서브리퀘스트는 별도이며([Workers Data Localization](https://developers.cloudflare.com/data-localization/how-to/workers/)), `workers.dev`에는 Regional Services와 Customer Metadata Boundary가 제공되지 않음([Data Localization compatibility](https://developers.cloudflare.com/data-localization/compatibility/)). Workers AI는 고객 콘텐츠를 동의 없이 모델 훈련·개선에 쓰지 않고 고객이 저장 서비스를 사용하지 않는 한 저장하지 않는다고 설명하지만, 이것만으로 정확한 처리 국가와 일시 처리 보유기간을 확정할 수 없음([Workers AI data usage](https://developers.cloudflare.com/workers-ai/platform/data-usage/)).

저장소의 `wrangler.toml`에는 D1·Workers AI 바인딩과 `workers.dev` 사용이 보이지만 D1 jurisdiction 또는 Regional Services 설정은 확인되지 않음. 설정 파일만으로 이미 생성된 D1의 실제 위치, DPA 체결 여부, 계약상 수탁관계, 하위처리자, Workers AI 처리 국가·보유기간을 증명할 수 없음.

## 6. 저장소 확인 사실과 미확인 사항

### 확인된 사실

- 앱 내 개인정보처리방침과 위치약관은 사업자 정보, Cloudflare 처리지역·계약관계, 확인자료 보관기간이 미확정이라고 직접 표시함.
- 동의 화면은 개인정보와 위치정보의 목적·항목·보유·거부 효과를 일부 표시함.
- 필수 동의 네 항목을 모두 선택하기 전 진행할 수 없도록 수정됨.
- 서버는 이용약관·개인정보·위치 문서별 동의 유형, 버전, 시각을 기록하도록 수정됐으며 운영 D1 마이그레이션 적용은 별도 작업임.
- 계정 삭제 시 사용자 행에 연결된 일부 데이터는 외래키 연쇄 삭제되지만, 무결성 이벤트의 사용자 참조는 `NULL`로 남을 수 있고 별도 보유·삭제 주기가 확인되지 않음.
- D1·Workers AI를 사용하지만 실제 Cloudflare 처리 위치와 계약 정보는 저장소에서 확인되지 않음.

### 반드시 외부 확인할 사항

- 사업자 법적 명칭, 법적 주소, 전화번호, 대표자, 개인정보 보호책임자·위치정보관리책임자와 연락처
- 개인정보 항목별 실제 보유기간, 로그·세션·동의 증적·무결성 이벤트·백업의 보유와 파기 주기
- 위치정보사업자 또는 위치기반서비스사업자 해당 여부, 신고·등록 필요 여부, 확인자료 종류·법적 근거·보관기간
- Cloudflare DPA 적용 여부, 계정 플랜, D1 실제 위치, Workers·Workers AI 처리 국가와 보유기간, 실제 활성 하위처리자
- 로그인·날씨·장소·경로 제공자별 제3자 제공 또는 처리위탁 구분, 국외 이전 국가·시기·방법·수령자 연락처·보유기간
- 일본 이용자 직접 대상 여부와 일본에서 취급하는 데이터·운영 주체

## 7. 수정 순서와 완료 기준

1. 수정된 필수 동의 판정과 문서별 동의 기록 마이그레이션을 운영 D1에 적용·검증해야 함.
2. 실제 사업자, 데이터 항목별 보유·파기, 위치정보 확인자료, 외부 제공자와 Cloudflare 계약 사실을 확정해야 함.
3. 확정 사실만으로 한국어 원문을 개정하고 개인정보처리방침·위치약관·동의 화면·서버 증적을 같은 버전으로 맞춰야 함.
4. 영어·일본어는 확정된 한국어 원문의 의미와 버전을 유지해 번역하고, 일본 직접 제공 시 APPI 추가사항을 반영해 현지 법률 검수를 받아야 함.
5. 문서 버전별 동의, 거부, 철회, 열람·정정·삭제·처리정지, 계정 삭제, 확인자료 기록·보존·파기와 백업 만료를 통합 검사해야 함.
6. 미확인 항목이 남은 초안을 사용자에게 최종 정책으로 노출하거나, 누락 사실을 면책 문구처럼 사용하면 안 됨.
