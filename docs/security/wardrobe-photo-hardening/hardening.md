# Security Hardening Review: 옷장 사진 업로드

## Evidence Basis

기준 리비전 `554bef0`의 모바일 선택·저장 흐름, Worker 분석 경계, App Attest, 권한 선언, 개인정보처리방침을 직접 확인했음. 현재는 이미지 재인코딩과 크기 제한, 로그인, App Attest 신호, 서버 미저장 안내가 있으나 비의류 사진을 실패-폐쇄 방식으로 거절하는 단일 정책 경계는 없음.

## Constraints

- 허용 대상은 한 장에 하나의 의류·신발·가방·착용 액세서리가 명확히 보이는 사진으로 한정함.
- 사람·얼굴·신체 중심 사진, 문서, 풍경, 반려동물, 음식, 화면 캡처, 불법·민감 콘텐츠, 다중 물체, 판별 불가 사진은 거절함.
- 분석 원본은 WeatherON 저장소에 저장하지 않고, 승인된 사용자의 정규화된 로컬 사본만 앱 샌드박스에 보관하는 구조를 유지함.
- 모델 오탐·미탐을 0으로 만들 수는 없으므로 보수적 임계값과 실패-폐쇄 정책을 사용함.
- 측정된 정확도·지연시간·메모리 예산은 아직 없음.

## Recommendation Summary

옵션 2를 권고함. 서버가 `accept/reject` 결정을 소유하고 승인 토큰 또는 분석 버전이 없는 신규 사진은 앱 상태에 들어오지 못하게 해야 함. 같은 경계에서 제한된 스트리밍 본문 읽기, 실제 이미지 시그니처·크기 검사, 사용자별 분당 제한과 일일 예산, 메타데이터 전용 로그, 명시적 폐기·정책 고지를 함께 적용해야 함.

옵션 3은 사람 사진 등이 Cloudflare 추론 경계에 도달하기 전에 차단할 수 있어 개인정보 측면에서 더 강함. 다만 네이티브 모델 용량, 기기별 성능, 두 플랫폼의 정확도 회귀 비용을 감수할 때 선택하는 편이 맞음.

## Next Decisions

- 옵션 2를 1차 릴리스로 선택할지, 옵션 3까지 한 번에 포함할지 결정 필요함.
- 사람 포함 사진을 전부 거절할지, 얼굴이 없고 의류가 주 피사체인 착용 사진은 허용할지 정책 결정 필요함.
- 분당·일일 분석 한도와 판별 코퍼스의 허용 오탐·미탐 기준 확정 필요함.
- 구현 전 개인정보처리방침의 Workers AI 이미지 처리, 전송 목적, 저장 여부, 보유 기간, 국외 처리 고지를 법무 검토해야 함.
