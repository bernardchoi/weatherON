# P2 권한·온보딩·계정 중단/복귀 — 2026-10-30

코드 수정 및 격리 회귀 검사 완료. 실제 OS 권한/설정 복귀와 TestFlight 검증은 미완료임. 과거 디자인 적용 기록은 결함 근거로 사용하지 않았음. 기존 미커밋 변경은 보존했으며 커밋·푸시·배포하지 않았음.

## 현재 출시 경로와 정책

- 첫 실행 O1 → 소개 O2 → 위치 선택 O7 → 알림 선택 O5 → 목적지 O6 → 검색 P1 또는 나중에 → 홈 H1. O4 스타일 설정은 별도 경로임.
- 위치·알림·목적지 등록을 나중에 선택해도 게스트 홈 진입 가능함. 목적지 저장은 현재 게스트 정책 그대로 유지함. 권한이 없으면 출발 알림은 켜지지 않음.
- 필요한 동작에서만 기존 O3 권한 gate와 A2/A3 계정·약관 gate 사용함. A4에서 계정 상태 확인 및 미완료 약관 재진입 가능함.
- 공식 로그인 버튼, 필수 동의 4개, 지역별 제공자 순서, 세션 토큰, 계정 연결 해제/삭제 및 기존 저장 데이터 정책은 변경하지 않았음.
- iOS 출시 증거는 Xcode Cloud 빌드 → TestFlight → 실제 iPhone 기준임. 로컬 개발 빌드와 브라우저 검증은 이를 대체하지 않음.

## 이번에 확인하고 수정한 문제

1. **재시작 시 온보딩 진행 손실**: 새 `localhost:8094` 웹 프로필에서 O5까지 진행 후 새로고침하면 O1로 돌아감. 현재 hydration이 미완료 사용자를 무조건 O1로 보내고 있었음. 기존 저장소에 단계·권한 선택 완료 여부·온보딩 목적지 선택 여부를 추가하고, 네이티브 SQLite 읽기/쓰기에도 연결했음. P1에서 중단하면 직전 O6로 복귀하고 선택한 목적지를 복구함. 완료 사용자는 H1로 시작함. 기존 저장값에는 O1 기본값을 적용함.
2. **권한 안내 재진입 시 선택 초기화**: O7/O5의 선택 완료 여부가 화면 내부 state에만 있었음. 공통 저장 상태로 옮겨 뒤로 가기와 재시작 때 다시 초기화되지 않게 했음. 허용 여부 자체는 OS 확인 결과로 갱신함.
3. **설정 복귀 후 위치 허용을 확인하지 않음**: 이전 거절로 manual이 되고 `locationReady=false`이면 권한 재확인 콜백이 바로 종료됐음. 해당 조기 종료를 제거했음. 권한 확인은 요청 팝업을 띄우지 않으며, 직접 고른 수동 위치 모드는 유지함.
4. **계정 취소 뒤 늦은 응답이 원래 동작을 실행함**: 실제 로그인/약관 콜백의 Promise를 보류한 격리 검사에서, 취소 이후에도 성공 응답이 저장 동작/화면 이동을 실행하는 경로를 확인했음. 취소·뒤로 가기 이후 응답은 인증 상태만 갱신하고 취소한 동작을 재개하지 않게 했음. 중복 탭도 차단했음. 시작 시 늦은 세션 복원 응답이 새 로그인 결과를 덮지 않도록 같은 revision을 확인함.

## 실행한 검사

통과:

```sh
node --no-warnings scripts/check-onboarding-recovery.mjs
node scripts/check-ios-launch-state.mjs
node scripts/check-permission-account-interactions.cjs
node scripts/check-account-region.mjs
node --no-warnings scripts/check-account-auth.mjs
node --no-warnings scripts/check-review-regressions.mjs
node --no-warnings scripts/check-correctness-batch.mjs
npx tsc --noEmit -p apps/mobile/tsconfig.json
```

`check-account-auth.mjs`는 메모리 DB와 격리 HTTP를 사용하는 기존 서버 검사임. 출력의 integrity 실패 로그는 의도된 거절 시나리오이며 검사 전체는 통과함. 실서비스 계정 연결·해제·탈퇴를 수행한 것이 아님.

`node scripts/check-android-product-quality.mjs`는 기존 미커밋 경로 변경과 소스 문자열 assertion 불일치로 중단됨:

```text
must include: originCountryCode: originLocation.countryCode
```

이번 변경에 필요한 온보딩 복원 assertion만 갱신했음. 경로 관련 종합 검사 실패는 별도 범위로 남김.

## 남은 실제 검증

- 새 네이티브 테스트 프로필에서 위치/알림 각각 허용·거절·나중에, 앱 재시작, OS 설정 변경 후 복귀 검사 필요함.
- 실서비스 인증은 승인된 테스트 계정으로 제공자 취소·네트워크 실패·재시도·약관 미완료 복원을 확인해야 함. 게스트 데이터가 있는 실제 계정의 연결 해제·탈퇴로 대신 검증하지 말 것.
- 약관 체크 초안은 기존처럼 실행 중에만 유지되며 재시작 후 재선택해야 함. 서버가 동의를 승인하기 전에는 동의 완료로 복원하지 않음.
- 테스트용 시뮬레이터 `WeatherON-P2-Isolated` (`5E30AAAF-2985-4E87-BF3C-96426B829B50`)는 종료 상태임. 빌드 성공·앱 설치·OS 검증 증거는 없음.
