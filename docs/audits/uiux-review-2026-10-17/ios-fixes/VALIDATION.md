# iOS UI/UX 개선 검증

기준: main 8217078 위 작업 중 변경. Ambient 배경·Glass·아이콘 유지함.

## 반영

- P1: 출발 목록을 도착 시점 예보로 변경하고, 안내에 날짜·시각 표시함. 해당 목적지 예보가 없으면 다른 장소 자료를 사용하지 않음.
- P1: 상세 현재값의 가용성·관측 시각·최근 자료 표시함. 빈 예보를 관측 카드로 대체하지 않음. 실제 0과 누락 구분함.
- P1: iOS 검색 요청에 관련성 순 모드 추가함. 서버 후보 수집과 캐시 키를 분리하고 앱은 관련성 후 거리 정렬함. 산업·부동산 등의 산 오분류 방지함.
- P2: 시간별 요약은 표시된 12시간으로 제한하고 날짜 표시함. 누락 구간은 강수 낮음으로 단정하지 않음.
- P2: iOS 검색어 지우기 버튼을 Glass 스타일 조건에서 분리함.
- P2: iOS 삭제 복구를 명시적 복구·닫기 전까지 유지함. UI·상태 이중 타이머와 화면 이탈 만료 제거함. 다른 플랫폼의 기존 시간 정책 유지함.
- P2: 코디의 자료 불확실·온도 미확인 상태에 기존 새로고침 동작 연결함.
- P3: 코디 상세 3개 이상은 기존 2열 배치를 사용해 긴 이름 공간 확보함. 사용자 중심 보유 설명으로 변경함.

## 자동 검증

- 모바일 TypeScript 검사 통과.
- check-ios-uiux 통과: iOS 관련성/기존 거리 정렬, 서버 캐시 분리, 산업 분류, 어댑터 누락 필드, 빈 예보, 실제 목록 도착 확률, 다른 장소 대체 금지, 실제 상세 가용성 조건의 누락/실제 0 처리.
- check-place-search-distance, check-today-outfit, check-ios-daily-forecast, check-home-outing, check:shared, check-destination-limit 통과.
- check-place-search의 실제 서비스 smoke는 환경변수 설정이 없어 실행되지 않음.
- git diff --check 통과.

## 실기기 검증

- 로컬 Xcode 27.1 Release 구성 + Apple Development 서명 빌드 성공함. Metro 없는 내장 JS 번들임.
- devicectl로 동일 bundle ID에 덮어 설치·실행 성공함. 저장 목적지 3개·옷장 5개 유지 확인함.
- iPhone 미러링에서 홈 강수 51%와 출발 목록의 `10/18 10:00 도착 무렵 · 강수확률 51%` 일치 확인함. [홈](./home.png), [목록](./destinations.png).
- 상세의 `관측 · 10/17 12:12`와 표시 12시간 범위의 강수 안내 확인함. 범위 밖 05:00 요약 사라짐. [상세](./weather-detail.png).
- 코디 상세 2열에서 긴 신발명과 보유 설명이 정상 표시됨. [코디 상세](./outfit-detail.png).
- 검색어 입력 후 X 버튼 노출·클릭 초기화·주변 목록 복귀 확인함. [지우기 전](./search-clear.png), [지운 후](./search-cleared.png).
- 미러링의 한글 키 전달은 자모로 분리됐고 붙여넣기는 전달되지 않아 서울역 실제 결과 검증은 못 함. 앱의 검색 정렬 자체는 회귀 검사로 확인함.
- 사용자 목적지를 삭제하지 않아 실제 삭제·복구, 정상 자료를 훼손하지 않아 실패 상태 재시도·누락 수치 화면은 기기에서 시험하지 않음. 해당 누락값은 실제 어댑터·상세 조건 실행으로 확인함.
- Xcode 초기 도구 설치·프로비저닝 갱신 후 빌드함. npm 복원으로 누락된 SQLite 생성 소스 복원 및 Pods 동기화 수행함. Pod 의존성 버전 변경 없음. Hermes·ReactCodegen 생성 체크섬 2개만 갱신됐음. Xcode 프로젝트 자동 정렬 변경은 제거함.
- 배포용 Xcode 설정 변경 없음. 검증 후 홈으로 복귀함.

실기기 정상 상태와 자동 누락값 검증은 구분함. VoiceOver·큰 글자·실제 통신 장애·실제 목적지 삭제 복구는 별도 검증 필요함.
