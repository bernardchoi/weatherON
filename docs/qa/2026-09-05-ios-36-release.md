# iOS 1.0.0 (36) 안정화 배포

## 변경 범위

- 스마트 알림 끄기 후 실제 예약 목록이 0건인지 확인하고, 취소 미완료를 성공으로 표시하지 않도록 보완.
- EAS 업로드에서 로컬 환경 파일, Cloudflare 로컬 상태, 로컬 worktree 제외.
- iOS 앱 설정과 네이티브 타깃 빌드 번호 36으로 정렬. Android 버전 유지.

## 검증

- 사진 등록·교체·삭제/복구·덮어쓰기 설치 후 보존: 로컬 Debug 실기기 검증 통과. 상세 기록은 `2026-09-05-ios-stability.md` 참조.
- 저장 실패·사진 교체·알림 경합·취소 미완료 회귀 검사 통과.
- 사진 상대 경로·복구 안내 만료, iOS 시작 상태, TypeScript 검사 통과.
- 플랫폼 버전 검사: Android 1.0.0 (16), iOS 1.0.0 (36).
- 해외 시간대 실기기 검증은 사용자 요청으로 제외.

## TestFlight 확인 항목

1. 기존 앱을 삭제하지 않고 업데이트한 뒤 직접 등록한 옷 사진이 남아 있는지 확인.
2. 앱 완전 종료 후 아이콘으로 실행해 홈 진입과 옷 사진 표시 확인. 시작 화면 지연 시 발생 시점과 지속 시간 기록.
3. 사진 아이템 삭제 직후 복구하고, 사진과 보유 개수 복원 및 복구 안내 제거 확인.
4. 스마트 알림 끄기 후 예약 0건 표시, 빠른 켜기·끄기와 재실행 후 꺼짐 유지 확인.

## 남은 범위

로컬 Debug에서 시작 지연 1회 관찰 후 재현되지 않았음. 시작 조건은 로컬 저장 복원·이미지 준비이며 서버 인증 복원과 분리되어 있음. 원인을 확정하거나 수정했다고 주장하지 않음. 아래 TestFlight 일반 실행 검증에서도 재현되지 않았음. 장시간 백그라운드 실수신과 다른 기기·iOS 조합은 이번 검증 범위에 포함하지 않음.

## 배포 상태

- 업로드 아카이브 검증 완료: 파일 1,262개, 로컬 환경 파일·인증서 파일 0개, 로컬 worktree 파일 제외. 앱 설정과 네이티브 타깃 4개의 빌드 번호 36 확인.
- 사용자가 Expo EAS 소스 업로드 및 App Store Connect 제출을 명시적으로 승인함.
- EAS production 원격 번호 35→36 증가 및 소스 업로드 완료.
- 빌드 ID: `ea1a76f8-caea-4d02-96d7-d04dd6d329e1`, 버전 `1.0.0 (36)`, 상태 `FINISHED`. 완료 시각 2026-09-05 19:35 KST.
- EAS의 테스트 안내 자동 등록 옵션은 Enterprise 요금제 제한으로 제출 예약 전에 거절됨. 해당 옵션만 제외하고 같은 빌드 ID 제출 재시도. 안내 문구는 이 문서의 TestFlight 확인 항목으로 보존.
- App Store Connect 제출 ID: `bba80de0-c928-4650-8043-6a4b78dc5886`, 상태 `FINISHED`.
- Apple 처리 `VALID`, 내부 TestFlight `IN_BETA_TESTING`, 외부 테스트 `READY_FOR_BETA_SUBMISSION`, 만료되지 않음 확인. 업로드 시각 2026-09-05 19:38 KST.
- 외부 테스트 심사·일반 App Store 정식 출시는 이번 제출에 포함되지 않음.
