## 변경과 근거

- 홈의 기존 라이트/다크 radial gradient를 공통 함수로 추출했다. 읽기 화면의 경로별 계정 PNG/별도 gradient 혼용을 제거하고 같은 바탕과 정적인 fold를 사용한다. 홈 승인 레이아웃과 날씨·상호작용 레이어는 유지한다.
- 옷장은 독립 필터 3개와 시트 앞쪽 선택 표시, 중복 제목/수량 정리, 중앙 빈 상태와 넓은 추가 버튼을 적용했다. 빈 상태 PNG는 승인된 `assets/brand/ambient-surface-ui-icons-final-v1-20261009/ui-outline/wardrobe.svg`를 512px로 변환한 파생 에셋이다. 보드의 열린 옷장 삽화와 완전히 같은 그림은 아니다.
- My Glass 카드의 행 스타일이 contained 패딩을 0으로 덮어써 유효 좌우 여백이 8pt였다. 마지막에 행 내부 12pt를 적용해 총 20pt로 조정했다. 카드 외부 폭·글자 크기·76pt 최소 행 높이·행 터치영역은 유지한다. 네이티브 Glass는 절대 위치 배경 형제이며 콘텐츠를 contentView에 넣지 않아, 이번 원인은 네이티브 패딩 유실이 아니라 RN 스타일 우선순위다.

## 검사 및 기기 확인

- TypeScript noEmit, ambient surface 회귀/대비, 코디 상호작용, 홈 복귀, 홈 ambient host 검사, diff 공백 검사 통과.
- Xcode 27, Debug iphoneos, ARM64 단일 작업, 기존 DerivedData를 재사용한 증분 빌드 성공. 무선 덮어 설치와 정상 실행 성공. 앱 삭제·데이터 초기화 없음.
- 직접 iPhone Mirroring으로 현재 라이트 화면의 홈→코디→옷장, 필터 전체→가을→재열기→전체 복원, My→표시 설정→My, 홈 복귀를 확인했다. 옷장 빈 상태 중앙 정렬/버튼/선명한 에셋, My 내부 여백과 값 정렬이 확인됐다. My 수정 이후 표시 설정 왕복도 확인했다.
- 네이티브 화면 전환 중 이전 화면 가장자리가 잡힌 프레임이 있으나 정착 후 사라졌다. 관찰한 경로에서 정착 후 홈 콘텐츠 누출이나 충돌은 보이지 않았다. 순간 프레임 전체 무결성을 보장하는 연속 영상 검증은 아니다.
