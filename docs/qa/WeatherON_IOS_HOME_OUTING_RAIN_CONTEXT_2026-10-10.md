# iOS Home 준비 안내·가독성·강수 문맥·체감온도 QA — 2026-10-10

## 최종 사용자 방향

처음 승인된 정보 역할 정리 뒤, 사용자가 작은 새 텍스트와 메타상태 중심 대표 문구를 지적했다. 최종 구현은 목적지의 확인된 조건으로 가장 필요한 준비 한 가지를 친근하게 안내한다. 기존 PRD의 기능 역할 정리이며 새 API·권한·인증정보·서명 설정 또는 Android 화면 변경은 없다. 기존 Ambient Surface/daylight 수정, 실제 설정·목적지·옷장 자료는 보존했다. 커밋·푸시는 하지 않았다.

- 현재 위치의 대형 기온과 같은 스냅샷의 실제 체감값을 표시한다. 실제 필드가 없는 체감값은 현재기온/시간별 기온으로 대체하지 않는다. 최근 정보 표시는 작은 보조상태로 분리한다.
- 대표 안내는 `목적지 도착 무렵` 또는 `목적지 현재 날씨` 기준을 명시한다. 확인되는 조건에 따라 우산·방수 겉옷·보온/바람막이 한 겹·물 등 행동 한 가지만 친근하게 안내한다. stale/fallback/예보 부족을 확신 있는 마케팅 문구로 꾸미지 않는다.
- 설정된 도착 날짜·시각의 실제 예보를 우선한다. 출발 기준 일정의 도착은 확인된 이동시간이 있을 때만 추정하고 `도착 예상`으로 구분한다. 해당 시각 예보가 없으면 실제 목적지 현재 조건만 사용하며 현재 기준·예보 부재를 짧게 표시한다. 귀가 시각은 만들지 않는다.
- 시간별 체감값이 없으면 일반 기온을 사용하고 `기온`으로 설명한다. 바람·기상상태·강수 필드도 원본 존재 근거가 있을 때만 사용한다. 숫자를 모두 나열하지 않고 대표 행동의 근거 하나만 아래에 남긴다.
- 대표 준비 카피는 26/34pt, 근거는 20/28pt, 강수 요약/코디 설명은 18/26pt로 정리했다. 작은 라벨·반복 위치명·코디 아이템명 나열을 줄이고 대형 온도와 주변 여백을 재배분했다. 큰 글씨/작은 화면은 자연스럽게 스크롤할 수 있으며 텍스트를 자르거나 강제 축소하지 않는다.
- 코디는 실제 추천 이미지 두 개가 조합을 설명한다. `현재 위치` 또는 `목적지` 중 실제 활성 날씨 기준을 친근한 한 줄로 표시한다. 전체 아이템명은 접근성과 기존 상세에 유지한다. 기존 H1/C1/C4 추천 결과를 바꾸거나 가짜 옷을 넣지 않는다.
- 독립 `예보` 버튼을 강수 요약에 연결된 `강수 예보`로 바꿨다. 기온 근거 전체는 강수 링크가 아니다. H5에 같은 위치 ID·기준 시각을 전달하고 최신 해당 위치 스냅샷을 읽는다. 위치 삭제 때 다른 위치로 대체하지 않는다.
- 실제 시간별 강수 항목만 표시한다. 빈 시간·누락 필드를 0으로 만들지 않고, fallback/공간 미확인 자료의 숫자 예보·관측시각을 표시하지 않는다. 마지막 강수 구간으로 종료/완화를 단정하지 않으며 현재 자료를 미래 예보로 설명하지 않는다.

## 원본 근거와 캐시 보존

WeatherKit 정규화의 기존 숫자 계약을 유지하면서 체감·기온·바람 및 시간별 기온/강수확률/강수량/바람/기상상태의 원본 필드 유무를 별도 메타데이터로 구분했다. 다른 위치의 날씨를 목적지 이름으로 relabel한 자료는 공간 미확인으로 처리한다. 신뢰도는 해당 위치 스냅샷의 관측시각·stale·fallback·공간 근거로 판단하므로 부분 실패가 다른 위치의 정상 자료를 일괄 무효화하지 않는다.

실기기에서 캐시 복원 시 메타데이터가 사라지는 경로를 발견했다. 날씨 캐시 표에 nullable `provider_presence_json` 열 하나를 비파괴·멱등 마이그레이션으로 추가해 원본 존재 boolean과 기존 시간별 키만 보존한다. 사용자 설정·목적지·계정·옷장 값은 변경하지 않는다. 근거가 없는 옛 캐시/손상 메타데이터는 계속 미확인으로 처리한다. 실제 체감값의 원본 근거가 보존된 이후 캐시는 재실행 때도 그 근거를 유지한다.

## 추가 사용자 방향: 좌우 균형·영역 재질

직전 설치 화면의 왼쪽 세로 밀집과 영역 구분 부족에 대한 사용자 지시를 반영했다. 사용자 첨부 원본을 공식 Library materialization 소비자 helper로 메타데이터와 함께 읽고 실제 픽셀을 확인했다.

- 큰 기온 옆에 작은 실제 날씨 아이콘·상태·체감·최고최저를 하나의 보조 그룹으로 배치했다. 기온 크기와 본문 크기를 유지한다. 보조 그룹도 Ambient 읽기 보호 영역에 포함한다.
- 대표 안내는 열린 배경에 두고 위아래 간격을 확보했다. 실제 목적지 도착 날짜·시각 기준은 보존한다.
- 목적지 선택과 출발 시간을 가로로 묶고 패널 내부 여백을 확보했다. 좁은 화면(390pt 미만) 또는 글씨 배율 1.3 초과는 세로로 흐른다. 원본 목적지 이름의 기존 한 줄 처리는 유지하고 접근성에는 전체 이름을 보존한다.
- `시간별 강수 · 강수 예보` 반복을 없애 `강수 예보` 하나로 정리했다. 실제 강수 근거가 있을 때 요약을 붙이며 신선도/불확실성 표시를 숨기지 않는다.
- 코디는 설명과 실제 추천 이미지를 좌우로 배치하고 더 옅은 톤 표면을 사용한다. 유리 박스를 반복하지 않는다. 좁은 화면/큰 글씨는 세로 배치, 자연 스크롤을 유지한다.

### 실제 Liquid Glass와 대체 표면

관련 플랫폼 skill은 macOS SwiftUI 중심이므로 iOS에 직접 적용하지 않고 재질 과사용 방지와 표준 재질 우선 원칙만 참고했다. Apple 공식 [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 및 [UIGlassEffect](https://developer.apple.com/documentation/uikit/uiglasseffect) 내용을 확인했다. 기능/내비게이션 영역에 유리를 제한하고 접근성 설정을 존중하라는 원칙에 맞춰, 목적지·시간·강수 제어 패널 한 곳에만 적용했다.

기존 native bridge의 동일 Swift/Objective-C 파일 안에 Home 전용 material view manager를 추가했다. iOS 26 이상과 등록된 모듈에서는 실제 UIKit `UIGlassEffect(.regular)`를 사용하며 `expo-blur` 모사가 아니다. 새 패키지·프로젝트 등록·서명/권한 변경은 없다. 배경 재질은 터치를 받지 않고 새 제스처·타이머·움직임 효과를 만들지 않는다. RN 전경 텍스트는 기존 명시적 테마 색을 유지한다. Reduce Transparency는 JS 및 native 알림/상태 모두 확인하며 불투명 톤 표면으로 바꾼다. 미지원 OS/이전 바이너리/등록 모듈 부재도 불투명 톤 표면이다. 코디 표면은 RN 톤 표면으로, Liquid Glass라고 설명하지 않는다.

### 최신 검사·설치 증거

8번째 순차 증분 빌드에서 위 레이아웃/네이티브 재질을 통합했다. Xcode 27, 기존 QA workspace·서명·derived data, ARM64/jobs1 조건으로 `BUILD SUCCEEDED`, 서명 검증·기기 설치 성공. 해당 설치 번들 SHA256은 `4fd7248342190eb749137133d97c0f331236a75b0d1b8fc145f5607ab4f3d4aa`다. 이후 앱 소스를 변경하지 않았다.

타입 검사, native module 검사, 실제 준비/강수/체감/SQLite/내비게이션/JSX 회귀, viewport, weather icon, Ambient response/surface와 localization 2,145 keys, diff whitespace 검사를 통과했다. 제거된 반복 표현 때문에 번역 키가 하나 줄었다. 실제 material component를 OS/모듈 유무/양쪽 테마/투명도 설정 조합으로 실행해 native 선택·불투명 대체·터치 미차단을 확인했다. 이 검사는 실제 OS 접근성 설정 체감 QA를 대신하지 않는다.

최신 기기 숫자 진단은 viewport 758 / content 758 / fontScale 0.882 / overflow 0이다. 처음 두 캡처에서는 상단에 검은 기기 오버레이가 겹쳤다. 콘솔을 종료한 뒤 같은 바이너리를 콘솔 없이 다시 열었으며, 최종 전체 Home 캡처에서는 해당 가림이 사라졌다. 이를 재빌드/재설치 없이 확인했다. 실제 현재 기온 24° 옆의 체감 26°와 최고/최저, 목적지의 선택된 다음 날 10:00 실제 기온 예보 22°에 기반한 대표 준비 안내, 목적지/출발 가로 배치와 유리 패널, 옅은 코디 표면을 확인했다. 디버그 warning toast는 남아 있으므로 경고 없음으로 판정하지 않는다.

이 결과는 해당 iPhone의 현재 light/KO/기존 글씨 배율에서의 픽셀·숫자 증거다. 실제 H5 링크 터치/반복 진입/뒤로가기/C1, 큰 글씨·다크·Reduce Transparency·VoiceOver, 별/유성/스크롤/터치 사용자 체감은 아직 미검증이다. 기기 접근성 설정·실제 사용자 자료는 바꾸지 않았다. 모든 개인 위치 화면과 기기/실행 자료는 Git 바깥 로컬 증거에만 보존한다. 커밋·푸시는 하지 않았다.
