# iOS Home 목적지 행과 루트 배경 유지 — 2026-10-10

## 승인 범위와 원인

기존 승인 레이아웃과 실제 UIKit `UIGlassEffect(.regular)`를 유지하면서, 긴 경로 안내가 목적지 이름을 밀어내는 문제와 탭 복귀 때 Home 장식 배경을 다시 생성하는 문제를 수정했다. 커밋·푸시는 수행하지 않았다. 기준 HEAD는 `b957702d2379aa8363cd7c7550fc9d7e6cb340cf`이다.

사용자 제공 영상의 실제 프레임에서 같은 목적지의 짧은 경로 확인 문구가 긴 fallback 안내로 바뀔 때 이름·펼침 표시가 사라짐을 확인했다. 우측 전환 뷰의 폭이 제한되지 않아 좌측 이름 영역을 소진했다. 별도로 HomeAmbientHost는 Home 이탈 시 장식 트리를 제거하고 복귀 시 다시 등록했으며, 네이티브 질감도 새 비동기 렌더와 무작위 원점으로 생성됐다. UIKit 유리 합성 자체의 초기 지연 기여도는 분리 측정하지 않았다.

## 변경

- iOS 목적지·출발 시각 행의 우측 폭을 제한하고 이름 영역과 펼침 버튼을 보존했다. 긴 경로 설명은 행 아래 패널 전체 폭에 표시한다. 기존 글자 크기, 전체 목적지 접근성 라벨과 44pt 터치 영역을 유지한다. 좁은 폭과 큰 글자는 기존 적층 배치를 사용한다. Android 안내 배치는 유지한다.
- Home 장식은 루트의 같은 컴포넌트 위치에 남는다. 다른 화면에서는 숨기고 애니메이션·터치 반응·태양 시각 타이머·신규 질감 렌더를 중지한다. 복귀 렌더는 루트의 최신 날씨·위치·시간대·테마를 사용한다. 이전 Home 터치 세션은 보존하지 않는다.
- 네이티브 질감은 크기와 테마가 같으면 재사용한다. 숨길 때 대기 작업을 취소하고 세대 번호로 늦은 결과를 폐기한다. 이미 실행 중인 단일 Core Image 호출을 강제로 중단하는 것은 아니며, 완료 결과를 표시하지 않고 후속 작업을 시작하지 않는다.
- Reduce Transparency, Reduce Motion, 저전력 정책과 실제 유리 패널을 유지했다. 테스트 테마 override, 신규 의존성·권한·외부 API는 추가하지 않았다.

## 추가 검증: 복귀 직후 연속 미러링 캡처

코드·빌드·설치·기기 설정 변경 없이 기존 iPhone 미러링의 지원 CUA API로 두 차례 Home↔코디 왕복 후 즉시 연속 캡처했다. 첫 회 5장, 두 번째 4장이다. API가 제공하는 자동 안정화 대기를 우회하지 않았다.

클릭 요청 시작을 0ms로 둔 호스트 측 호출 구간:

| 회차 | 클릭 호출 종료 | 첫 screenshot 호출 시작–종료 | 후속 screenshot 호출 종료 |
| --- | ---: | ---: | --- |
| 1 | 145ms | 145–564ms | 623, 685, 736, 786ms |
| 2 | 136ms | 136–554ms | 610, 661, 719ms |

두 회차 모두 첫 반환 이미지에 본문·Ambient 배경·목적지 유리 패널이 함께 보였다. 이후 이미지에서 배경 또는 패널이 뒤늦게 나타나는 현상은 관찰하지 못했다. 코디에서는 Home 배경이 보이지 않았으며 마지막은 원래 목적지를 유지한 Home 상태다.

이 시간은 API 호출 구간이며 실제 iPhone 표시 시각이나 정확한 픽셀 취득 timestamp가 아니다. 최초 캡처 호출 자체가 약 418–419ms 소요됐고, 후속 캡처는 약 50–62ms 간격이지만 이미 복귀 초기 구간이 지난 뒤다. 미러링 전송 지연도 분리할 수 없다. 따라서 0–약 550ms의 본문/배경/Glass 표시 순서, 한두 프레임의 번쩍임, UIKit 합성 지연 유무는 판정 불가다. 첫 이미지가 554ms에 반환됐다는 것을 554ms까지 지연이 없었다는 증거로 해석하지 않는다.

지원 API는 고속 녹화·안정화 대기 해제·기기 프레임 시각을 제공하지 않는다. 원격 기기 녹화 미지원이라는 기존 제한을 유지했고, 새 캡처 권한이나 설치를 요청하지 않았다. 남은 지연이 입증되지 않았으므로 추가 코드 수정 없이 정상 설치본을 유지한다. 시각적 완성도 전체 PASS는 보류한다. 초기 구간을 확정하려면 실제 기기에서 촬영된 프레임 시각을 가진 영상 등 별도 근거가 필요하다.
