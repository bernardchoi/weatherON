# iOS 목적지·이동 안내 실기기 QA — 2026-09-08

## 검증 기준

- 기기: iPhone 16 Pro Max, iOS 27.0
- 앱: `com.weatheron.mobile`, 로컬 Debug 서명 빌드
- 빌드: `WeatherON.xcworkspace` / `WeatherON` scheme, Xcode beta
- 설치: 기존 앱 위에 덮어설치. 설치 전후 CoreDevice database UUID가 같아 앱 데이터 유지 확인
- 조작·화면 확인: iPhone 미러링으로 실제 기기 터치 및 화면 관찰

## 발견 및 조치

- 최초 빌드는 성공했지만 실행 시 `[runtime not ready]: Cannot find native module 'ExpoClipboard'`로 차단됨.
- 원인: `expo-clipboard` JS 의존성은 존재했으나 iOS Pods에 `ExpoClipboard`가 반영되지 않았음.
- `pod install`로 `Podfile.lock`과 Pods를 동기화한 뒤 재빌드·덮어설치함.
- 재빌드의 의존성 그래프에서 `ExpoClipboard` 타깃 포함 및 `BUILD SUCCEEDED` 확인함.
- 수정 설치 후 같은 오류 없이 홈 화면 콜드 실행됨.
